# 배포 확인 항목

빌드 검사와 실제 PC 검증은 별도다. 아래 항목은 결과가 기록되기 전까지 미확인이다.

| 환경 | 확인할 결과 | 상태 |
|---|---|---|
| GG 없음 | 동의 후 공식 최신 설치·서명 확인, Sonar 설정 연결 | 미확인 |
| 설치 거절·취소·권한 거부 | Jack 신규 설치 중단, 재시도 가능 | 미확인 |
| GG 최신 설치됨 | 중복 설치 없음, 기존 설정 유지 | 미확인 |
| GG 구버전 설치됨 | 버전 안내·동의 후 업데이트, 거절하면 기존 설치 유지 | 미확인 |
| 오프라인·조회 실패 | 최신으로 표시하지 않음, 기존 설치 유지·재시도 | 미확인 |
| GG 중지·Sonar 비활성화 | 실행·활성화 안내 후 다시 연결 | 미확인 |
| Streamer 모드 | Classic 전환 안내, 미지원 제어 차단 | 미확인 |
| 가상 장치 미준비·재부팅 | 완료로 오인하지 않음, 재실행 시 설정 재개 | 미확인 |
| 실제 장치 연결 | 그룹 출력·앱 배정·볼륨·실제 재생·녹음 | 미확인 |
| Jack 업데이트 | 서명 검증, 경로 복구, 재시작·설정·시작 실행 보존 | 미확인 |
| 잘못된 업데이트 서명 | 적용 차단, 기존 앱 유지 | 미확인 |
| GG 종료·삭제·업데이트 | 충돌·재설치 반복 없음, 설정·복구 접근 가능 | 미확인 |
| Jack 제거·재설치 | GG·사용자 설정 유지, 시작 실행 항목 정리 | 미확인 |

자동 화면·동작 검사는 실행하지 않는다. 실제 Windows 확인 결과는 사용자가 확인한 범위로 기록한다.
