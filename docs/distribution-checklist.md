# 배포 확인 항목

빌드 검사와 실제 PC 검증은 별도다. 아래 항목은 결과가 기록되기 전까지 미확인이다.

2026-10-15 사용자 요청에 따라 추가 테스트와 다른 PC 검증은 이번 배포의 완료 조건에서 제외하고 이후 함께 진행한다. 미확인 표기는 그대로 유지한다.

| 환경 | 확인할 결과 | 상태 |
|---|---|---|
| GG 없음 | 동의 후 공식 최신 설치·서명 확인, Sonar 설정 연결 | 미확인 |
| 설치 거절·취소·권한 거부 | Jack 신규 설치 중단, 재시도 가능 | 미확인 |
| GG 최신 설치됨 | 중복 설치 없음, 기존 설정 유지 | 사용자 확인 |
| GG 구버전 설치됨 | 버전 안내·동의 후 업데이트, 거절하면 기존 설치 유지 | 미확인 |
| 오프라인·조회 실패 | 최신으로 표시하지 않음, 기존 설치 유지·재시도 | 미확인 |
| GG 중지·Sonar 비활성화 | GG 실행·활성화 후 다시 연결 | 0.1.3 다시 시도 사용자 확인. 0.1.4 버튼의 GG 실행·Sonar 비활성화는 미확인 |
| Streamer 모드 | Classic 전환 안내, 미지원 제어 차단 | 미확인 |
| 가상 장치 미준비·재부팅 | 완료로 오인하지 않음, 재실행 시 설정 재개 | 미확인 |
| 실제 장치 연결 | 실제 출력·마이크 | 사용자 확인 |
| 시작 실행·업데이트 UI | 기본 ON, ON/OFF 변경, Bald 업데이트 행·토스트 | 0.1.1 사용자 확인 |
| Jack 업데이트 | 재시작·설정·앱 배정·시작 실행 보존, 실제 출력·마이크 | 0.1.1 → 0.1.3 사용자 확인. 0.1.6은 기존 키·서명·변조 거부·공개 주소와 Rust 업데이터의 0.1.5 버전 모의 조회/다운로드 검증 통과. 실제 0.1.5 → 0.1.6 설치·재시작·오디오는 미확인 |
| 잘못된 업데이트 서명 | 적용 차단, 기존 앱 유지 | 미확인 |
| GG 종료·삭제·업데이트 | 충돌·재설치 반복 없음, 설정·복구 접근 가능 | 미확인 |
| Jack 제거·재설치 | GG·사용자 설정 유지, 시작 실행 항목 정리 | 미확인 |

자동 화면·동작 검사는 실행하지 않는다. 실제 Windows 확인 결과는 사용자가 확인한 범위로 기록한다.

2026-10-16: [0.1.7 릴리즈](https://github.com/mightyidler/Jack/releases/tag/v0.1.7)를 정식 공개하고 Latest로 지정했다. [배포 작업](https://github.com/mightyidler/Jack/actions/runs/38844422742)의 전체 검사·서명된 설치 파일 생성·초안 검증·공개 다운로드 검증이 통과했다. 이 PC에서도 `node tools/verify-release.mjs --published artifacts/distribution/v0.1.7`로 공개 업데이트 주소, 익명 다운로드, 기존 공개 키 호환성, Rust 업데이터 manifest 파싱, 설치 파일 서명과 변조 거부를 재확인했다. 설치 파일 SHA256은 `62e8df170b0b3dae348d1e8c5d0fa5685cc272c542e69beb6319e1e79054bcf9`이다. 실제 기존 앱에서 0.1.7 업데이트 설치·재시작·오디오 동작은 미확인이다.

현재 사용 가능한 PC는 기존 GG가 설치된 한 대다. GG를 제거하거나 별도 Windows 환경을 구성하지 않는다.

## 실제 확인 절차

- 현재 PC: GG를 트레이에서 종료하고 Jack 설정·업데이트 접근을 확인한다. GG를 다시 실행하고 Sonar가 준비되면 Jack에서 다시 시도한다. 기존 장치·앱 배정과 출력·마이크를 확인한다.
- GG 없는 별도 PC가 준비되면: 릴리스의 설치 파일을 실행해 GG 설치 거절 시 Jack 설치가 중단되는지 확인한다. 다시 실행해 동의 후 공식 GG 설치·Sonar Classic 설정·장치 연결을 마친 뒤 Jack의 출력·마이크를 확인한다.
- 취소·권한 거부·재부팅: 완료로 표시되지 않는지 확인하고, 재실행 시 기존 GG를 재사용하며 설정을 이어갈 수 있는지 확인한다. 기존 PC에서 이를 재현하려고 GG를 제거하거나 다운그레이드하지 않는다.

설치 보조 스크립트의 모의 검사에서는 동의·공식 주소·서명·중복 설치·다운그레이드 방지와 설치/업데이트/재부팅/취소/실패 분기, 임시 파일 정리를 확인했다. 실제 설치 프로그램은 실행하지 않았으며 위 표의 실제 환경 검증을 대체하지 않는다. 업데이트 패키지는 앱의 공개 키로 서명을 확인하고 변조된 바이트의 거부를 확인했다.
