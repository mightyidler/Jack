# 배포 상태

- 공개 저장소: https://github.com/mightyidler/Jack
- 공개 릴리스: https://github.com/mightyidler/Jack/releases/tag/v0.1.3 (2026-10-15). 설치 파일·업데이트 서명·latest.json을 제공한다.
- 기존 GG 설치를 재사용한다. 공식 최신 주소는 https://steelseries.com/gg/downloads/gg/latest/windows 이다.
- 공식 최신 GG 121.0.0의 제품 정보와 유효한 GN Hearing A/S 서명을 확인했다(2026-10-15).
- 사용자 확인: 기존 GG로 설치·연결·출력·마이크 정상. 0.1.1 시작 실행 스위치·Bald 업데이트 행·토스트 정상.
- 사용자 확인: 앱에서 0.1.1 → 0.1.3 온라인 업데이트·재시작 후 시작 실행 값·앱 배정 유지, 출력·마이크 정상. 설치 경로의 실행 중인 파일 버전도 0.1.3이며 시작 실행 등록을 유지한다.
- 0.1.3의 연결 다시 시도는 사용자 확인했다. 0.1.4에서는 버튼 디자인·처리 상태를 보완하고, 명시적 다시 시도 시 꺼진 GG를 실행하도록 변경했다. 변경판의 실제 화면·GG 실행 확인은 별도다.
- 사용자 요청에 따라 추가 테스트와 다른 PC의 실제 검증은 이후로 미룬다. 현재 배포 작업의 완료 조건에서는 제외하며 아래 미확인 항목을 통과로 바꾸지 않는다.
- 소스·빌드·업데이트 서명·변조 거부·압축 CSS 타이밍 검사를 통과했다. 실제 오디오·화면 자동 검사는 실행하지 않았다.
- Jack 전용 업데이트 비밀 키는 소스 밖과 GitHub Secrets에 둔다. Windows Authenticode 코드 서명은 적용하지 않았다.
- Rust는 로컬에서 확인한 1.95.0으로 고정했다. GitHub Actions에서 0.1.3 빌드·테스트·서명·변조 거부 검사를 통과했다. 공개 주소의 설치 파일이 검증된 파일과 동일하며 로그인 없이 다운로드됨을 확인했다.
- 실제 GG 설치를 실행하지 않는 검사에서 설치 동의·중복 설치·다운그레이드 방지, 최신 설치·업데이트·재부팅 결과, 취소·서명 거부·제품 불일치·HTTP 실패·임시 파일 정리를 확인했다. Windows PowerShell 5.1과 PowerShell 7에서 통과했다.
- 현재 PC만 사용할 수 있어 GG 미설치·구버전·재부팅 환경의 실제 설치는 미확인이다. 기존 GG를 제거하거나 변경하지 않는다. 다른 장애 환경의 확인 상태는 배포 확인 항목을 참고한다.
