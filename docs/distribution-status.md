# 배포 상태

- 공개 저장소: https://github.com/mightyidler/Jack
- 0.1.11 공개 전 검증(2026-10-17): v0.1.10 태그 이후의 변경 및 미커밋 신규 모듈·검사 도구를 검토했다. 출력 동기화는 기존 장치·볼륨·설정 저장 트랜잭션을 재사용하며 실패 시 롤백하고, 마이크는 독립적으로 유지한다. UI 부분 갱신 키와 볼륨 바인딩, 휠 입력의 직렬화·병합, 외부 변경 시 기대값 갱신과 충돌 거부, 구조화된 오류와 번역 경로를 확인했다. 릴리즈 차단 결함은 발견하지 못했다. Rust 139개·프런트엔드 36개·배포 회귀 4개 테스트와 fmt/Clippy/TypeScript/프로덕션 CSS/305개 의존성 라이선스/GG 설치 모의 검사가 통과했다. 기존 1421 웹 미리보기의 메인·트레이·마이크 검사와 0.1.11 네이티브 개발 앱의 실제 볼륨 IPC·외부 변경·휠·충돌 거부 검사가 통과했다. 실제 Sonar의 동기화 활성화·그룹별 볼륨 복원 검사도 통과하고 원래 장치·볼륨 복구를 확인했다. 기록은 `artifacts/audio-quality`와 `artifacts/output-sync/v0.1.11-live.json`에 보존했다. 기존 앱에서 업데이트 설치·재시작 후 오디오 동작은 별도 미확인이다. 서명 패키지와 공개 경로 검증은 배포 후 추가 기록한다.
- 0.1.10 공개 완료(2026-10-16): [릴리즈](https://github.com/mightyidler/Jack/releases/tag/v0.1.10)를 Latest로 지정했다. 앱 태그 커밋은 `ce809d2e83db690423deb863fbd2f8f76dade04c`이며 [배포 작업](https://github.com/mightyidler/Jack/actions/runs/38881970149)의 전체 검사·서명된 설치 파일 생성·초안 검증·공개 다운로드 검증이 통과했다. Apple Music/Apple TV의 패키지 경로별 이름과 공식 아이콘 표시, 비활성 세션의 실행 경로 기반 아이콘 조회를 포함한다. Rust 134개·프런트엔드 27개·배포 회귀 4개 테스트와 fmt/Clippy/TypeScript/프로덕션 CSS/라이선스 검사가 통과했다. 현재 PC에서도 공개 업데이트 정보·익명 다운로드·기존 공개 키 호환·Rust 업데이터 manifest 파싱·설치 파일 서명·변조 거부를 재확인했다. 설치 파일 SHA256: `9aa88dec4081c0d134d687dee14a869b80f04bedd75f7458fe7e3dbebfe00fdc`. 파일은 `artifacts/distribution/v0.1.10`에 보존했다. 0.1.9와 업데이트 공개 키·앱 식별자·설치 모드도 동일하다. 실제 앱 내 업데이트 설치·재시작·오디오 동작은 미확인이다.
- 0.1.6 공개 완료(2026-10-16): 버전·Cargo/npm lock 동기화, 기존 0.1.4·0.1.5 공개 키·앱 ID·설치 모드 유지 확인. Rust 125개 테스트, 프런트엔드 17개 테스트, 배포 회귀 4개 테스트, fmt/Clippy/TypeScript/프로덕션 CSS/라이선스 검사 통과. 실제 오디오를 조작하는 테스트는 실행하지 않았다.
- 0.1.5 장애 원인: GitHub 빌드는 성공했지만 릴리즈가 초안으로 남았다. 인증 없는 릴리즈 API와 앱의 `releases/latest/download/latest.json`은 0.1.4를 반환해 기존 0.1.4에서 0.1.5를 발견할 수 없었다. 사용자는 직접 다시 설치했다. CI에 업로드 파일 재검증·정식 공개·Latest 지정·익명 업데이트 경로 검증을 추가했다.
- 0.1.5 이전 실패 로그도 대조했다. `38710658446`은 태그 v0.1.5와 앱 설정 0.1.4의 불일치, `38711681362`·`38711748554`는 Cargo.lock 불일치로 라이선스 검사에서 중단됐다. 0.1.6은 Cargo/npm 버전과 잠금 파일을 함께 갱신하고 `--locked` 검사·빌드를 필수 실행한다.
- 실제 설치된 `%LOCALAPPDATA%/Jack/jack-desktop.exe`의 제품 버전은 0.1.5이며, 동일한 업데이트 공개 키와 공개 endpoint가 바이너리에 포함된 것을 확인했다. 실제 앱 내 설치·재시작은 별도 확인이다.
- 0.1.6 서명 빌드 후 공개 전 검사에서 Tauri Action의 GitHub API asset URL을 발견해 공개를 차단했다. 설치 파일 ID와 일치하는 API URL만 정식 공개 다운로드 주소로 변환하도록 수정했다. 서명된 설치 파일은 그대로 유지하고 재다운로드한 manifest·서명·변조 거부·기존 버전 키 호환 검사를 로컬에서 통과했다. 설치 파일 SHA256: `1778c93c5c4608fd16c15d73a7011620d4c07df63d991fbd85f38b199ba9b0a2`.
- 공개 릴리스: https://github.com/mightyidler/Jack/releases/tag/v0.1.6 (2026-10-16). 설치 파일·업데이트 서명·latest.json을 제공하며 Latest로 지정했다. 공개 API, 인증 없는 앱 endpoint와 설치 파일·서명 다운로드를 GitHub runner와 현재 PC에서 모두 확인했다.
- 배포 작업 https://github.com/mightyidler/Jack/actions/runs/38821572155 성공. 앱 태그 커밋은 `d8ed888bb8d3e0a040867cbe89b87584a5ac56f1`이며 서명 빌드는 `38819708719`에서 완료됐다. 후속 배포는 앱·의존성·툴체인·라이선스 소스가 태그와 동일함을 확인한 뒤 메타데이터만 수정하고 공개했다.
- 현재 PC에서 창·오디오 초기화·설치를 실행하지 않는 별도 Tauri probe에 현재 버전 0.1.5를 지정했다. 앱과 같은 `tauri-plugin-updater 2.14.0`이 공개 endpoint에서 0.1.6을 발견하고 8,290,974바이트 설치 파일을 다운로드해 서명 검증을 통과했다. 실제 설치된 앱의 버튼 조작·설치·재시작·오디오는 미확인으로 남긴다. 기록은 `artifacts/distribution/v0.1.6-verification.json`과 관련 로그에 보존했다.
- 기존 GG 설치를 재사용한다. 공식 최신 주소는 https://steelseries.com/gg/downloads/gg/latest/windows 이다.
- 공식 최신 GG 121.0.0의 제품 정보와 유효한 GN Hearing A/S 서명을 확인했다(2026-10-15).
- 사용자 확인: 기존 GG로 설치·연결·출력·마이크 정상. 0.1.1 시작 실행 스위치·Bald 업데이트 행·토스트 정상.
- 사용자 확인: 앱에서 0.1.1 → 0.1.3 온라인 업데이트·재시작 후 시작 실행 값·앱 배정 유지, 출력·마이크 정상. 0.1.3 연결 다시 시도도 확인했다.
- 최종 0.1.4를 현재 PC에 설치했다. 다시 시도는 같은 색의 아이콘·텍스트와 전체 너비 버튼을 사용하며 연결 안내를 제목·설명으로 나눈다. 연결 전 그룹·대기 문구는 숨기고, 명시적 다시 시도 시 꺼진 GG를 실행한다. 최종 UI와 GG 실행의 실제 확인은 이후로 미뤘다.
- 다른 PC의 실제 검증은 이후로 미룬다. 실제 앱 내 업데이트·재시작·오디오 검증과 패키지/공개 경로 자동 검증을 구분하며 미확인 항목을 통과로 바꾸지 않는다.
- 이전 배포에서 소스·업데이트 서명·변조 거부 검사를 통과했다. 최종 UI 변경은 설치 파일 빌드에 필요한 검사만 진행했다. 실제 오디오·화면 자동 검사는 실행하지 않았다.
- Jack 전용 업데이트 비밀 키는 소스 밖과 GitHub Secrets에 둔다. Windows Authenticode 코드 서명은 적용하지 않았다.
- Rust 1.99.1, Node.js 26.12.0, npm 11.20.0을 사용한다. GitHub Actions의 태그 배포에서 소스·단위 검사는 필수다. 0.1.3은 Actions 빌드를 통과했고, 최종 0.1.4는 완료된 로컬 서명 빌드를 게시했다.
- 실제 GG 설치를 실행하지 않는 검사에서 설치 동의·중복 설치·다운그레이드 방지, 최신 설치·업데이트·재부팅 결과, 취소·서명 거부·제품 불일치·HTTP 실패·임시 파일 정리를 확인했다. Windows PowerShell 5.1과 PowerShell 7에서 통과했다.
- 현재 PC만 사용할 수 있어 GG 미설치·구버전·재부팅 환경의 실제 설치는 미확인이다. 기존 GG를 제거하거나 변경하지 않는다. 다른 장애 환경의 확인 상태는 배포 확인 항목을 참고한다.
