앱 시작 시 자동 업데이트를 보완하고 장치 선택과 트레이 화면의 전환을 다듬었습니다.

- 메인 창이나 트레이 화면의 표시 여부와 관계없이 앱 시작 시 업데이트를 한 번 확인하고, 새 버전이 있으면 서명 검증 후 설치·재시작합니다.
- 업데이트 확인·다운로드에 시간 제한을 적용하고, 실패 시 다음 실행에서 다시 확인하도록 했습니다. 설정의 수동 확인도 유지합니다.
- 입력 장치 선택 시 선택 배경·체크 표시·볼륨 상태가 자연스럽게 이어지도록 개선했습니다.
- 트레이 화면 전환과 높이 변경이 빠른 연속 조작에도 현재 위치에서 이어지도록 개선했습니다.
- 탭 표시기, 장치 전환, 드롭다운과 팝업의 모션과 시각 효과를 다듬었습니다.

Windows 11 x64용이며 SteelSeries GG / Sonar Classic이 필요합니다. 기존 업데이트 공개 키와 설치 경로를 유지합니다. Jack은 SteelSeries의 공식 제품이 아닙니다.

자동 검증은 소스·단위 검사, 빌드된 CSS, 업로드된 패키지의 서명·변조 거부, 기존 버전 공개 키와의 호환성, 공개 업데이트 주소와 익명 다운로드를 포함합니다. 실제 앱 내 업데이트 후 재시작·오디오 동작은 별도 확인 항목입니다.
