오디오 그룹과 프로그램 이동을 다듬고 드래그 중 발생하던 위치·스크롤 문제를 해결했습니다.

- 프로그램을 집으면 살짝 커지고, 옮길 때 출발·도착 그룹의 높이와 주변 항목이 부드럽게 이어집니다.
- 같은 그룹과 다른 그룹의 프로그램 사이 또는 맨 마지막에 원하는 순서로 놓을 수 있습니다. 지정한 순서는 저장되며 프로그램을 다시 실행해도 유지됩니다.
- 드래그 중 원래 항목이 중복으로 남거나 불필요한 빈 공간이 생기던 문제를 수정했습니다.
- 화면 아래쪽에서 드래그 항목과 그룹이 위아래로 반복해서 튀던 문제를 수정했습니다.
- 헤더 바로 아래에서도 위쪽 자동 스크롤이 시작되도록 개선했습니다.
- 빈 영역에 놓으면 놓은 위치에서 원래 자리로 돌아갑니다. 화면 왼쪽 위로 순간이동하거나 원래 항목이 겹쳐 보이던 문제를 수정했습니다.
- 프로그램 구분선 여백을 왼쪽 44px·오른쪽 0px로 맞췄습니다.
- 오디오 그룹 추가·삭제와 탭 표시기의 모션을 다듬었습니다.
