설정의 환경 메뉴에서 언어와 테마 변경이 제대로 반영되지 않는 문제를 수정했습니다.

- 언어를 바꾸면 환경 설정의 제목·설명, 드롭다운 문구와 선택 표시가 새 언어로 갱신됩니다.
- 테마를 바꾸면 화면 색상과 선택 표시가 함께 갱신되며, 이전 테마로 다시 변경할 수 있습니다.
- 환경 설정 갱신 시 스위치 행만 유지하고 드롭다운을 새 설정으로 생성해, 이전 선택값과 이벤트 처리가 남는 원인을 제거했습니다.
- 변경 전 시작된 조회 응답이 최신 설정을 덮어쓰지 않도록 했습니다. 처리 중이거나 화면에서 제거된 드롭다운의 추가 선택도 차단합니다.

Windows 11 x64용이며 SteelSeries GG / Sonar Classic이 필요합니다. 기존 업데이트 공개 키와 설치 경로를 유지합니다. Jack은 SteelSeries의 공식 제품이 아닙니다.
