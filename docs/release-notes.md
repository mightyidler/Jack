출력 장치 동기화와 볼륨 조절, 외부 오디오 변경 시 화면 갱신을 개선했습니다.

- 출력 장치 동기화를 켜면 모든 그룹이 게이밍 그룹의 출력 장치를 즉시 사용합니다. 바뀌는 그룹은 해당 장치에 저장된 볼륨을 0%까지 복원하며, 적용·저장 실패 시 이전 오디오 상태로 복구합니다. 마이크는 독립적으로 유지합니다.
- 볼륨 행에서 휠은 5%, Shift+휠은 1%씩 조절합니다. 연속 입력은 병합하고 작은 트랙패드 이동량은 누적합니다.
- 외부 볼륨 변경 시 기존 컨트롤을 유지하며 표시와 다음 조작의 기준값을 갱신합니다. 앱 목록과 장치 변경은 영향을 받는 부분만 갱신합니다.
- 연결 해제된 출력을 실제 0%와 구분하고 마지막 볼륨을 유지합니다. 연결이 끊겨도 다른 출력 장치를 선택할 수 있습니다.
- 장치 이름에서 USB·드라이버 설명을 줄이고 같은 이름은 번호로 구분합니다. 툴팁에서는 원본 이름을 확인할 수 있습니다.
- 오디오 작업 실패 시 한국어·영어 해결 안내를 표시합니다.

Windows 11 x64용이며 SteelSeries GG / Sonar Classic이 필요합니다. 기존 업데이트 공개 키와 설치 경로를 유지합니다. Jack은 SteelSeries의 공식 제품이 아닙니다.
