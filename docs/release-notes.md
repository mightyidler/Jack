Spotify 등 앱을 다시 실행할 때 오디오 그룹이 잠시 바뀌면서 음량이 달라지는 문제를 수정했습니다.

- 한 번 완료된 앱별 그룹 배정은 앱 재실행과 Jack 종료·업데이트·재시작 후에도 유지됩니다.
- 앱이 종료돼 출력 설정을 조회할 수 없는 상황을 경로 복원 요청으로 잘못 처리하지 않습니다.
- Sonar나 Windows에서 사용자가 바꾼 출력은 Jack 재시작 후에도 존중합니다. Jack에서 직접 다시 배정하면 새 선택을 적용합니다.
- 명시적인 배정 해제·그룹 삭제·초기화와 실제 실패 복구에는 필요한 경로 복원을 유지합니다. 종료된 앱의 복원 요청도 저장합니다.
- Sonar가 현재 스트림을 이동할 수 없는 경우 다음 재생에 사용할 앱별 출력 설정을 저장합니다.

Windows 11 x64용이며 SteelSeries GG / Sonar Classic이 필요합니다. 기존 업데이트 공개 키와 설치 경로를 유지합니다. Jack은 SteelSeries의 공식 제품이 아닙니다.

현재 PC의 네이티브 개발 빌드에서 Spotify 3회 재실행 모두 처음부터 Media로 재생되고 Gaming으로 이동하지 않는 것을 확인했습니다. Jack 종료·업데이트 대기·재시작의 배정 유지, 외부 출력 변경의 저장·유지, 명시적 재배정도 검증했습니다. 기존 설치판의 0.1.13 업데이트 설치·재시작과 별도 PC 환경은 별도 확인 대상입니다.
