Apple Music과 Apple TV를 프로그램 목록에서 이름과 공식 아이콘으로 구분할 수 있도록 개선했습니다.

- 두 앱의 오디오 프로세스가 같은 `AMPLibraryAgent` 이름으로 표시되던 문제를 수정했습니다. 실제 실행 경로를 확인해 Apple Music 또는 Apple TV로 표시합니다.
- 각 앱의 설치 패키지에 포함된 공식 아이콘을 사용합니다.
- 재생이 멈춰 오디오 세션 정보가 없는 상태에서도, 실행 중인 프로그램의 경로를 확인해 아이콘을 표시합니다.

Windows 11 x64용이며 SteelSeries GG / Sonar Classic이 필요합니다. 기존 업데이트 공개 키와 설치 경로를 유지합니다. Jack은 SteelSeries의 공식 제품이 아닙니다.

자동 검증은 소스·단위 검사, 빌드된 CSS, 업로드된 패키지의 서명·변조 거부, 기존 버전 공개 키와의 호환성, 공개 업데이트 주소와 익명 다운로드를 포함합니다. 실제 앱 내 업데이트 후 재시작·오디오 동작은 별도 확인 항목입니다.
